## 이번 릴리스에 포함된 주요 기능

1. **PDF 기준 필기 페이지 비율 보존 (핵심 기하 엔진 개편)**
   - 대상 PDF와 원본 필기의 페이지 비율이 달라도 대상 PDF의 크기·비율·회전을 온전히 유지.
   - 필기 좌표계 캔버스 역변환(`canvas_transform`)을 통해 필기가 본문 위치에 맞게 안전하게 옮겨짐.
   - Samsung Notes, Notewise, Goodnotes 6 세 형식 모두 지원 및 저장 후 검증.
2. **선택적 쪽 제외(Page Exclusion) 기능 (신규 UI/기능)**
   - 필기 이전 검토 화면에서 특정 페이지를 "결과에서 제외 / 다시 포함"할 수 있는 버튼과 시각적 스타일 제공.
   - 제외된 페이지를 빼고 결과 아카이브를 온전히 재조립하도록 백엔드 전 경로 연결 완료.
3. **실기 검증 세트 구축**
   - 실제 강의자료를 바탕으로 960x540 → 960x702 세로 30% 늘린 검증 파일 및 시각 대조 PNG 생성 도구 마련.
4. **README 문서 최신화**
   - 기능 목록에 쪽 제외 및 PDF 비율 보존 추가.

## 남아 있는 과제

- **실기 검증 (태블릿 확인)**: `tmp/실기검증/` 세트의 각 형식 파일을 실제 태블릿 앱에서 열어보고 펜/지우개 편집 동작 확인.
- **정렬 품질 기준 과제 (열린 질문)**: 쪽 크기가 다르고 본문 배치가 특이할 때 정렬 추정 잔차가 큰 경우(Goodnotes 특정 자료)에 대한 거절/경고 정책 설계.
- **PR #2 (Goodnotes 목차 기능)**: `9b1535e` 비율 변환 코드 위로 리베이스 대기.
