# NotEditor 리브랜딩과 데스크톱·웹 배포 인계

**날짜:** 2026-08-26
**기기:** LAPTOP
**관련 명세:** `docs/specs/2026-08-26-03-NotEditor-리브랜딩과-데스크톱-웹-배포.md`

## 현재 상태
제품·Python 패키지를 NotEditor/`noteditor`로 리브랜딩하고 문서 합치기와 필기 옮기기를 동급 탭으로
재구성했다. 데스크톱 pywebview 브리지와 세션 격리 FastAPI 웹 API가 같은 UI·처리 엔진을 사용한다.
Docker 정의, PowerShell 원터치 설치, PyInstaller+Inno Setup 설치 파일 자동 빌드, GitHub Actions와
README까지 작성했다. 코드는 `f6eb390`에 커밋됐고 현재 작업 트리는 깨끗하다. 이 인계 커밋 뒤에
비공개 `kynbeen/NotEditor` 원격을 생성·연결·푸시할 예정이다.

## 이번 세션에 한 일

- 저장소 작업 경로를 `C:\dev\NotEditor`, Python 패키지를 `noteditor`로 정리했다.
- 모든 앱 제목, AppUserModelID, 로그 경로, 바로가기, 실행 명령을 NotEditor로 변경했다.
- 문서 합치기와 필기 옮기기를 헤더의 동급 탭으로 만들고 모달 구조를 제거했다.
- 결과 패널의 별도 도구 행을 제거해 세 패널 제목부/내용부 경계를 73px로 맞췄다.
- PDF/SDOCX 선택·업로드·분석·미리보기·저장 중 전체 또는 내부 로딩 표시를 연결했다.
- 실제 필기 투명 레이어, 페이지 직접 입력, 휠 이동, 세로 드래그 스크롤을 유지·검증했다.
- FastAPI 웹 어댑터를 추가해 PDF 합치기와 필기 이전의 업로드·미리보기·다운로드를 구현했다.
- 웹 파일을 HttpOnly 쿠키 세션별 임시 폴더에 격리하고 만료·초기화·응답 후 정리하도록 했다.
- Dockerfile/Compose, GitHub 테스트·Release 워크플로, PyInstaller spec, Inno Setup 정의를 추가했다.
- `install.ps1` 한 번으로 venv·의존성·아이콘·바로가기를 설치하도록 했다.
- README를 Windows 설치, 웹 실행, Docker 배포, 폴더 구조, 제한 사항 기준으로 다시 썼다.
- 전체 89개 테스트, JavaScript/Python/YAML/PowerShell 구문 검사를 통과했다.
- PyInstaller로 `dist/NotEditor/NotEditor.exe`를 빌드했고 숨김 실행 5초 스모크 테스트를 통과했다.

## 내린 결정과 근거

- 저장소 루트 아래 `noteditor` 패키지를 유지한다. Python import·정적 자원·패키징 경계를 루트의
  문서·설치·배포 파일과 분리하기 위한 의도된 중첩이다.
- 웹과 데스크톱은 UI 파일을 복제하지 않고 런타임에 pywebview 또는 HTTP API를 자동 선택한다.
- 웹 결과는 서버 경로를 노출하지 않고 즉시 다운로드하며 임시 출력은 응답 후 삭제한다.
- 특정 클라우드 설정 대신 Docker 표준을 제공한다. 사용자가 업체 중립 배포를 선택했다.
- 비공개 GitHub 저장소를 사용한다. 따라서 외부 사용자는 초대받거나 설치 파일을 별도로 전달받아야 한다.

## 고려했다가 안 한 것

| 대안 | 왜 안 했나 |
|---|---|
| Python 코드를 저장소 루트에 평탄화 | 런타임·자원·테스트 경계가 흐려지고 표준 import 패키지를 잃는다. |
| GitHub Pages에 처리 앱 배포 | PDF/SDOCX 처리는 Python 서버가 필요해 정적 호스팅만으로 실행되지 않는다. |
| 웹앱만 남기기 | 사용자가 Windows 데스크톱과 웹을 모두 유지하기로 선택했다. |
| 기존 잠긴 폴더를 강제 삭제 | `samples/`와 venv가 남아 있어 사용자 데이터를 손상시킬 수 있다. |

## 미해결 질문 / 블로커

- 이 기기에 Docker가 없어 실제 `docker build`는 실행하지 못했다. Docker/YAML 정의와 HTTP 서버는 검증했다.
- 연결 가능한 브라우저 인스턴스가 없어 클릭·스크린샷 기반 시각 검증은 못 했다. UI 정적 계약과 HTTP
  통합 테스트는 통과했다.
- Samsung Notes 결과의 태블릿 실기기 열기 검증은 계속 남아 있다.
- `C:\dev\pdf-page-composer` 루트가 Windows 프로세스에 잠겨 제자리 이름 변경과 삭제가 거부됐다.
  커밋된 저장소는 `C:\dev\NotEditor`에 새로 만들었고, 옛 폴더의 `samples/`와 venv는 보존했다.
