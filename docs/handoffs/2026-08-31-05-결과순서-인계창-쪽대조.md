## 이번 세션에 한 일

### ① "현재 결과 순서는 합치기 인계 규격에 손실 없이 기록할 수 없습니다" — 원인과 수정

사용자 신고: `1주차(1)` 30-50쪽과 `1주차(2-1)` 1-16쪽을 합치려는데 저장이 막혔다.
앱 로그(`%LOCALAPPDATA%\NotEditor\app.log`)에 16:26:46 `save_result` →
`parts_from_order` 예외가 그대로 남아 있었다.

원인은 `syncOrder` 였다. `orderDirty` 인 동안 **새로 고른 쪽을 결과 목록 맨 끝에 붙였다.**
그래서

1. A 범위를 30-50 으로 잡고
2. B 범위를 1-16 으로 잡은 다음
3. **A 로 돌아와 범위를 넓히면**

새로 들어온 A 쪽이 B 뒤에 붙어 `A[30-50] + B[1-16] + A[51]` 이 된다. 규격은 문서당 한 구간만
표현할 수 있어 거절된다. Node 로 옛 코드를 그대로 돌려 이 순서를 재현했다.

고친 것 둘:

- `insertNearOwnBlock` — 새 쪽을 **같은 문서의 기존 구간 안에 쪽 번호 순서대로** 끼운다.
- `applyStartupPlan` 이 계획을 무조건 `orderDirty = true` 로 두던 것을 없앴다. 빈 계획(수집함에서
  처음 고르는 합치기)에서도 dirty 라 사용자가 순서를 손댄 적이 없는데 이 경로로 들어갔다.

회귀 테스트는 `tests/test_order_sync.py` — `app.js` 에서 함수를 잘라 Node 로 실제 실행한다
(파이썬으로 옮겨 적으면 진짜 코드를 검사하지 못한다). Node 가 없으면 skip.

### ② 인계 창은 그 일만 한다

- `필기 옮기기` 탭 비활성(`lockToMergeTool`). 도구를 바꿔 나가면 인계를 끝내지 않은 창이 남고
  summary.ai 는 결과를 영영 기다린다.
- 합치기 모드 저장 버튼 문구 → `저장하고 summary.ai로 돌아가기`.
- 저장·`갱신`·`넘어가기` 뒤 `returnToSummaryAi()` → `close_window()` 로 **자기 창을 닫는다.**
  `ComposerApi.close_window` 는 **인계로 열린 창에만** 허용한다.

### ③ 쪽 대조 화면

- 창 전체가 세로로 스크롤된다(`body { overflow-y: auto }`), 도구 막대는 `sticky`.
- 대조 구역은 내용만큼 길어진다(`review-mode { height: auto }`, 행 목록 `overflow: visible`).
- 쪽 높이 `clamp(160px, 21vh, 300px)` — 1440×900 에서 **세 쌍이 온전히 보이는 것을 실측**했다.
- `다른 쪽` 이전/다음 버튼으로 달라진 행만 건너뛴다.
- 합친 자료는 **고른 쪽 범위 안(`inside`)과 바로 옆(`adjacent`)** 변경을 따로 강조한다.
  범위는 `startup_plan` 결과의 새 칸 `recorded_ranges` 로 화면에 전달한다.

## 내린 결정과 근거

- **순서를 자동으로 정렬해 주지 않는다.** 사용자가 일부러 끈 순서를 말없이 바꾸는 셈이 된다.
  자동으로 나쁜 순서가 만들어지지 않게 고치고, 손으로 만든 것은 규격대로 거절한다.
- **`close_window` 를 인계 창으로 제한.** 그냥 실행한 NotEditor 를 웹 화면이 닫으면 안 된다.
- **summary.ai 창을 여기서 찾아 올리지 않는다.** 그러면 NotEditor 안에 summary.ai 지식이
  들어간다. 결과를 회수한 쪽이 자기 창을 올린다.
- **쪽 높이를 `vh` 로.** 세 쌍이 들어가는지는 창의 세로 길이가 정한다. `vw` 로 재면 넓고
  낮은 창에서 세 쌍이 화면 밖으로 밀린다.

## 고려했다가 안 한 것

| 대안 | 왜 안 했나 |
|---|---|
| 규격을 고쳐 문서가 여러 구간에 나오게 허용 | 판 올림이 양쪽 저장소에 걸린다. 화면 쪽 원인이 명확해 그쪽을 고쳤다. |
| 대조 쪽을 더 크게 | 세 쌍이 한 화면에 안 들어간다. 두 요구가 부딪혀 3쌍을 우선했다. |
| `필기 옮기기` 탭을 인계 때 숨기기 | 왜 못 쓰는지 읽을 자리가 사라진다. 비활성 + 설명으로 남겼다. |
