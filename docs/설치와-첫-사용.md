# NotEditor 설치하고 처음 써 보기

컴퓨터에 익숙하지 않아도 그대로 따라 할 수 있게 썼습니다. 순서대로만 하면 됩니다.

**NotEditor가 하는 일은 두 가지입니다.**

- **문서 합치기** — 여러 PDF에서 필요한 쪽만 골라 원하는 순서로 새 PDF를 만듭니다.
- **필기 옮기기** — Samsung Notes·Notewise·Goodnotes 6에 해 둔 필기를, 배경 PDF만 새것으로
  바꿔 그대로 옮깁니다. 교재가 개정판으로 바뀌었을 때 필기를 다시 하지 않아도 됩니다.

> **파일은 이 컴퓨터 밖으로 나가지 않습니다.** 문서를 서버에 올리지 않고 내 PC 안에서만
> 처리합니다. 인터넷은 설치할 때만 씁니다.

---

## 준비물

- **Windows 10 또는 11** (64비트)
- 인터넷 연결 (설치할 때만)

Python 같은 걸 따로 깔 필요는 **없습니다.** 설치 파일 안에 다 들어 있습니다.

---

## 1단계 · 설치하기

두 가지 방법이 있습니다. **방법 A를 권합니다.**

### 방법 A · 파일 하나 받아서 설치하기 (권장)

1. 아래 주소를 눌러 다운로드 페이지를 엽니다.

   **<https://github.com/kynbeen/NotEditor/releases/latest>**

2. 페이지를 아래로 내리면 **Assets**(첨부 파일) 목록이 있습니다.
   거기서 이름이 이렇게 생긴 파일을 누릅니다.

   ```
   NotEditor-Setup-1.0.0.exe
   ```

   (`1.0.0` 자리 숫자는 버전에 따라 다릅니다. **`.exe`로 끝나는 파일**을 고르면 됩니다.
   `Source code (zip)`은 개발자용이니 누르지 마세요.)

3. 다운로드된 파일을 **두 번 눌러 실행**합니다.

4. **여기서 파란 경고창이 뜹니다. 정상입니다.** ⬇︎ 아래 «파란 경고창이 떴어요»를 보세요.

5. 「사용자 계정 컨트롤」 창이 뜨면 **[예]** 를 누릅니다.

6. 설치 마법사에서 계속 **[다음]** 을 누르고 마지막에 **[설치]** 를 누릅니다.

7. 끝났습니다. 바탕화면과 시작 메뉴에 **NotEditor** 아이콘이 생깁니다.

### 방법 B · 명령 한 줄로 한 번에 (원터치)

직접 다운로드하고 실행하는 과정을 한 번에 끝냅니다.

1. 키보드에서 **Windows 키**를 누르고 `powershell` 이라고 칩니다.
2. **Windows PowerShell** 을 눌러 엽니다.
3. 아래 줄을 **통째로 복사해서** 붙여넣고 **Enter** 를 누릅니다.

```powershell
iwr https://raw.githubusercontent.com/kynbeen/NotEditor/main/install-online.ps1 -OutFile "$env:TEMP\NotEditor-install.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\NotEditor-install.ps1"
```

최신 버전을 찾아 내려받고 설치까지 알아서 합니다. 중간에 「사용자 계정 컨트롤」 창이 뜨면
**[예]** 를 누르세요. `설치가 끝났습니다` 가 나오면 완료입니다.

> 이 명령이 하는 일은 **최신 릴리스 조회 → 설치 파일 내려받기 → 실행**, 이 세 가지가
> 전부입니다. 내용이 궁금하면
> [`install-online.ps1`](../install-online.ps1) 을 먼저 읽어 보셔도 됩니다.

## 파란 경고창이 떴어요

**「Windows의 PC 보호」** 라는 파란 창이 뜨고 실행이 막힐 수 있습니다.

> Windows에서 PC를 보호했습니다
> Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.

**바이러스라는 뜻이 아닙니다.** 유료 코드 서명 인증서를 사지 않은 프로그램에는 Windows가
일단 이 경고를 띄웁니다. 개인이 만든 프로그램은 대부분 이 화면을 만납니다.

**넘어가는 방법:**

1. 창 안의 **「추가 정보」** 를 누릅니다. (작은 글씨입니다)
2. 아래에 나타나는 **[실행]** 버튼을 누릅니다.

백신 프로그램이 파일을 지워 버리는 경우도 드물게 있습니다. 그럴 때는 백신에서
`NotEditor-Setup-….exe` 를 예외로 등록한 뒤 다시 받으세요.

---

## 2단계 · 실행하기

바탕화면이나 시작 메뉴에 아이콘이 **두 개** 생깁니다. 아무거나 써도 되고, 하는 일은 같습니다.

| 아이콘 | 무엇이 다른가 | 언제 쓰나 |
|---|---|---|
| **NotEditor** | 프로그램 창으로 열립니다 | 보통 이걸 쓰세요 |
| **NotEditor 로컬 웹** | 인터넷 브라우저 창으로 열립니다 | 위쪽이 안 열릴 때 |

둘 다 내 PC 안에서만 돌아갑니다. 「로컬 웹」도 인터넷에 올라가는 게 아니라, 내 컴퓨터
안에서만 열리는 주소(`127.0.0.1`)를 씁니다.

---

## 3단계 · 써 보기

### PDF 여러 개를 하나로 합치기

1. **[PDF 추가]** 를 눌러 파일을 고릅니다. 여러 개 골라도 됩니다.
2. 왼쪽 목록에서 문서를 누르면 가운데에 모든 쪽이 보입니다.
3. 넣고 싶은 쪽을 눌러 고릅니다. `1-3, 5, 8-` 처럼 범위로 한 번에 골라도 됩니다.
4. 순서를 바꾸려면 쪽을 끌어다 놓습니다.
5. 오른쪽 위에 저장할 이름을 적고 **[PDF로 저장]** 을 누릅니다.

원본 PDF는 **하나도 바뀌지 않습니다.** 새 파일이 따로 생깁니다.

### 필기를 새 교재로 옮기기

위쪽 **[필기 옮기기]** 탭을 누릅니다.

1. **1번 칸** — 필기가 들어 있는 원본을 고릅니다.
   - Samsung Notes → `.sdocx`
   - Notewise → `.notewise`
   - **Goodnotes 6 → `.goodnotes`**
2. **2번 칸** — 필기를 옮겨 붙일 **새 PDF**(예: 개정판 교재)를 고릅니다.
3. 잠시 기다리면 두 문서의 쪽을 **자동으로 짝지어** 줍니다. 쪽이 늘거나 줄어도, 여백이나
   크기가 달라져도 본문을 기준으로 맞춥니다.
4. 화면에서 **왼쪽(옛 배경)과 오른쪽(새 배경)을 나란히** 비교하며 필기가 제자리에 오는지
   확인합니다. 틀린 짝은 끌어서 고칠 수 있습니다.
5. 각 줄을 확인 처리한 뒤 저장하면, 원본과 **같은 형식**으로 새 파일이 나옵니다.

원본 필기 파일과 PDF는 **건드리지 않습니다.** 새 파일만 생깁니다.

### Goodnotes 6에서 `.goodnotes` 파일 꺼내기

NotEditor에 넣으려면 Goodnotes 앱에서 먼저 파일로 내보내야 합니다.

1. Goodnotes 6에서 옮기고 싶은 **노트를 엽니다.**
2. **공유 / 내보내기** 메뉴를 엽니다.
3. 형식에서 **PDF가 아니라 「Goodnotes 문서」** 를 고릅니다.
   → `.goodnotes` 파일이 만들어집니다.
4. 그 파일을 Windows PC로 옮긴 뒤 NotEditor의 1번 칸에 넣습니다.

> **PDF로 내보내면 안 됩니다.** PDF는 필기가 그림처럼 눌러 붙은 상태라 다시 편집할 수
> 없습니다. 반드시 **「Goodnotes 문서」** 로 내보내세요.

> ⚠️ **Goodnotes 6 지원은 실험 기능입니다.**
> 저장한 결과를 Goodnotes 앱에서 다시 열어 확인하는 검증이 아직 끝나지 않았습니다.
> **중요한 노트는 원본을 반드시 따로 보관한 뒤** 사용하세요.
> 잘 되는지/안 되는지 알려 주시면 큰 도움이 됩니다.

## 잘 안 될 때

| 이런 일이 | 이렇게 하세요 |
|---|---|
| 파란 「PC 보호」 창에서 막힘 | 위 «파란 경고창이 떴어요» 참고 — 「추가 정보」 → **[실행]** |
| 창이 열리다 마는 것 같음 | **NotEditor 로컬 웹** 아이콘으로 실행해 보세요 |
| 「앱 연결을 찾을 수 없습니다」 | 창을 닫고 **바로가기 아이콘**으로 다시 실행하세요 (브라우저 즐겨찾기로 열면 안 됩니다) |
| 필기 옮기기에서 쪽이 안 맞음 | 두 문서의 **쪽 크기·회전**이 다르면 자동 정렬합니다. 그래도 이상하면 화면에서 짝을 직접 끌어 고치세요 |
| 「페이지 크기가 다른데 … 정렬 배율을 정할 수 없습니다」 | 두 PDF 중 하나가 거의 비어 있거나 스캔 품질이 낮아 기준을 못 잡은 경우입니다. 다른 PDF로 시도해 보세요 |
| 백신이 파일을 지움 | 백신에서 `NotEditor-Setup-….exe` 를 예외 등록 후 다시 받으세요 |

문제가 계속되면 **문제 신고**를 남겨 주세요:
<https://github.com/kynbeen/NotEditor/issues>

무엇을 하다가 어떤 문구가 나왔는지 적어 주시면 가장 빠릅니다. 아래 기록 파일을 같이
첨부해 주시면 더 좋습니다.

```
%LOCALAPPDATA%\NotEditor\app.log
```

(Windows 키 + R → 위 줄 붙여넣기 → Enter)

## 최신 버전으로 올리기

새 버전이 나오면 **설치할 때와 똑같이** 하면 됩니다. 덮어써서 설치되고, 설정이나 파일이
지워지지 않습니다. 방법 B의 명령 한 줄을 다시 실행해도 같습니다.

## 지우기

**설정 → 앱 → 설치된 앱** 에서 **NotEditor** 를 찾아 **제거**를 누릅니다.
만들어 둔 PDF나 필기 파일은 지워지지 않습니다.
